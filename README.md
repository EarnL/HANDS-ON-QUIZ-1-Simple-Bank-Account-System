# 🚀 Overview

This repository contains the code and testing evidence for **Hands-On Quiz 1**.  
The project demonstrates the creation and management of bank account records using Django's powerful ORM.

### ✅ Features
- Deposit Function
- Withdraw Function
- Getter and Setter Methods
- Balance Validation
- Django ORM Integration
- Django Shell Testing
